# 내사랑 누룽지 홈페이지

따뜻한 끓임누룽지 3종과 바삭한 스낵누룽지 4종을 소개하는 브랜드 홈페이지입니다.

- 홈페이지 주소: https://joyunho-cmd.github.io/HOME/
- 구매: https://smartstore.naver.com/nrgstore

## 파일 구성
- `index.html` · 페이지 뼈대
- `content.js` · 상품·캐릭터 내용
- `app.js` · 화면과 메뉴 이동
- `theme.css` · 디자인(색감·글씨·애니메이션)
- `images/top-banner.jpg` · 최상단 배너 (원본 고해상도 파일로 같은 이름으로 덮어쓰면 선명해집니다)
- `characters/*.svg`, `gen_chars.py` · 2D 캐릭터 7종과 생성 스크립트

`main` 브랜치에 올리면 GitHub Pages로 자동 배포됩니다.
